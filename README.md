# 🎮 TileVania - 2D Platformer Game

A classic 2D platformer game developed using **Unity** and **C#**, based on the *TileVania* project from the [GameDev.tv](https://www.gamedev.tv/) Unity 2D course.

This project was created to practice and solidify fundamental game development concepts, including responsive player movement, 2D physics, collision detection, state-based animations, and modular level design.

---

## ✨ Features

* **🏃 Player Movement:** Fluid running, jumping, and ladder-climbing mechanics.
* **🗺️ Tilemap-Based Levels:** Multi-layered platformer environments built using Unity's built-in Tilemap and Rule Tile systems.
* **⚙️ Physics & Collisions:** Responsive player and environment interactions powered by Unity's 2D physics engine.
* **🎬 Character Animations:** Smooth state transitions (Idle, Running, Climbing, Dying) managed through Unity's Animator Controller.
* **👾 Enemies & Hazards:** Patrolling enemies and environmental hazards (spikes, water) that challenge the player.
* **🪙 Collectibles & Progression:** Interactive pickups (coins) placed throughout the levels alongside a scene-persistence and level-exit system.

---

## 🛠️ Technologies Used

* **Game Engine:** Unity (2D)
* **Programming Language:** C#
* **Level Design:** Unity Tilemap & Grid System
* **Physics & Collisions:** `Rigidbody2D`, `CapsuleCollider2D`, `BoxCollider2D`, `TilemapCollider2D`
* **Animation:** Unity Animator & Sprite Sheets
